# 第 2 章 功能结构

## 2.1 功能树

```
SensorHub 蓝牙传感器中枢
│
├── 1 设备发现与连接
│   ├── 1.1 BLE 扫描（过滤无名设备、按 RSSI 排序）
│   ├── 1.2 信号强度分级显示（3 格）
│   ├── 1.3 GATT 连接与服务发现
│   ├── 1.4 Notify 订阅（CCCD 两步走）
│   └── 1.5 断线自动重连（指数退避 + 抖动）
│
├── 2 实时数据
│   ├── 2.1 协议帧解析（流式 + CRC 校验）
│   ├── 2.2 数值卡片（温度/湿度/气压/光照/海拔）
│   ├── 2.3 实时曲线（环形缓冲 Canvas 自绘）
│   ├── 2.4 卡尔曼滤波平滑开关
│   └── 2.5 链路质量统计（丢包率 / CRC 错误率）
│
├── 3 设备控制
│   ├── 3.1 LED 亮度（PWM 0-255）
│   ├── 3.2 LED 开关
│   ├── 3.3 蜂鸣器短鸣
│   ├── 3.4 采样周期设置（200ms - 10s）
│   └── 3.5 强制上报（立即取一帧）
│
├── 4 自动化规则
│   ├── 4.1 规则增删改（阈值 / 比较符 / 动作）
│   ├── 4.2 连续命中 N 次才触发（防抖）
│   ├── 4.3 触发后冷却 5 秒（防刷屏）
│   └── 4.4 滞回比较器（避免在阈值上反复横跳）
│
├── 5 数据持久化
│   ├── 5.1 读数自动入库
│   ├── 5.2 历史列表分页浏览
│   ├── 5.3 按时间范围清空
│   └── 5.4 WorkManager 定期裁剪（保留 7 天 / 上限 10000 条）
│
├── 6 设置
│   ├── 6.1 模拟数据源开关（无硬件演示）
│   ├── 6.2 自动重连开关
│   ├── 6.3 通知开关
│   ├── 6.4 手动 MAC 直连（权限被拒时降级）
│   └── 6.5 关于信息
│
└── 7 桌面小组件（伴生模块 P1）
    ├── 7.1 RemoteViews 布局
    ├── 7.2 点击小组件唤醒 App
    └── 7.3 数据变化时广播更新
```

| # | 界面 | 类 | 布局 | 主要控件 |

| 1 | 主容器 | `MainActivity` | `activity_main.xml` | BottomNavigationView + NavHostFragment |

## 2.4 数据流向

```
ESP32 传感器 ──I2C──▶ ESP32 主控
                        │ 组帧 (CRC16)
                        ▼
                   NimBLE Notify (20B 分包)
                        │
                        ▼
        Android BLE 协议栈 ──onCharacteristicChanged──▶ BleConnection
                                                          │ callbackFlow
                                                          ▼
                                                     FrameParser（流式解析）
                                                          │ CRC 校验
                                                          ▼
                                              ┌───────────┴───────────┐
                                              ▼                       ▼
                                        SensorRepository        RuleEngine
                                              │                       │
                                    ┌─────────┴────────┐              ▼
                                    ▼                  ▼        触发动作（写特征值）
                              Room 落库          UI 更新（StateFlow）
                                    │
                                    ▼
                              小组件广播更新
```

反向控制流：

```
UI 点击 ──▶ ViewModel ──▶ BleConnectionManager.sendCommand()
          ──▶ buildCommandFrame(CRC16) ──▶ 写 CHAR_CTRL
          ──▶ ESP32 解析 ──▶ 执行（PWM / 蜂鸣）──▶ 回 ACK
```

## 2.5 权限清单

| 权限 | 用途 | 被拒后降级方案 |
|------|------|---------------|
| `BLUETOOTH_SCAN` | 扫描周边 BLE 设备 | 设置页手动输入 MAC 直连 |
| `BLUETOOTH_CONNECT` | 建立 GATT 连接 | 无法连接，提示用户去设置开启 |
| `POST_NOTIFICATIONS` | 前台服务通知 / 告警通知 | 降级为 App 内横幅提示 |
| `FOREGROUND_SERVICE` | 后台维持连接 | 仅前台使用，不影响核心功能 |
| `ACCESS_FINE_LOCATION` | Android 11 及以下扫描必需 | 同蓝牙权限降级 |

> 注：Android 12（API 31）起，BLE 扫描权限与位置权限解耦，但 Android 11 及以下仍需位置权限才能拿到扫描结果，故在 manifest 中以 `maxSdkVersion="30"` 声明位置权限。
