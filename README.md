# PixelLab 像素工坊 · C1 智能图像处理

Android 课程设计（C 档挑战级）——纯手写图像信号处理工具，不依赖任何图像处理库。

## 功能

| 模块 | 说明 |
|---|---|
| 卷积滤镜引擎 | 通用 3×3 卷积（锐化 / 边缘检测 / 浮雕 / Sobel 垂直边缘）+ 可分离高斯模糊 O(N·2k) + BT.601 灰度化 |
| 几何变换 | 旋转 90°、1:1 / 4:3 / 16:9 裁剪 |
| 文字识别 | ML Kit 中文识别（bundled 离线模型） |
| 批量处理 | WorkManager 后台队列，多选 9 张整批套用滤镜，进度上报、失败跳过 |
| 图像统计 | 处理前后灰度直方图对比 + 9 项量化指标（μ / σ / 极值 / 中位数 / 众数 / 信息熵 / 过曝欠曝率 / RGB 均值） |
| 全屏查看器 | 微信式大图查看：捏合缩放、双击放大、拖动平移、鼠标滚轮缩放 |
| AI 助手 | 可拖拽浮窗球 + 离线关键词问答（滤镜原理 / 使用流程 / 省略模型服务） |
| P4 分享卡片 | 处理前后对比 + 指标 + 水印，FileProvider 调起系统分享 |
| P1 桌面小组件 | 最近一次处理记录，保存即刷新 |

## 结构

```
android/app/src/main/java/com/pixellab/app/
├── image/      # 卷积核、高斯、灰度、直方图、变换引擎
├── worker/     # 批量处理 CoroutineWorker
├── share/      # 分享卡片生成
├── widget/     # P1 桌面小组件
├── data/       # Room 数据库、DataStore 设置
└── ui/         # 图库 / 编辑 / 相机 / 批量 / 统计 / 设置 / 查看器 / AI 助手
```

## 构建

Android Studio 打开 `android/` 目录，minSdk 26，AGP 9.5 + Gradle 9.6。

## 单元测试
